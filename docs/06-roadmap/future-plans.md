# 未来规划

## 当前版本: v2.0.0

TalentMail v2.0.0 已实现完整的邮件平台功能。以下是规划中的未来改进方向。

---

## 短期 (v2.1.x)

### 国际化 (i18n)

- [ ] 前端多语言支持框架 (@nuxtjs/i18n)
- [ ] 中文 / English 双语切换
- [ ] 日期时间本地化
- [ ] 错误消息本地化
- [ ] 管理后台语言切换

### 日历增强

- [ ] 周视图 / 日视图
- [ ] CalDAV 协议支持 (与 Thunderbird/Apple Calendar 同步)
- [ ] 循环事件支持 (RRULE 展开)
- [ ] 共享日历 (组织内共享)
- [ ] 日历推送提醒 (WebSocket / 浏览器通知)
- [ ] .ics 导出

### 搜索增强

- [ ] 联系人全文搜索
- [ ] 云盘文件名搜索
- [ ] 日历事件搜索
- [ ] 全局统一搜索 (邮件 + 联系人 + 文件 + 事件)

---

## 中期 (v2.2.x)

### S/MIME 加密

- [ ] S/MIME 证书管理
- [ ] 自动签名验证
- [ ] 证书导入/导出
- [ ] 与现有 PGP 共存

### CI/CD 集成

- [ ] GitHub Actions 自动化部署
- [ ] Docker Hub 镜像发布
- [ ] 自动化测试 (pytest + Playwright)
- [ ] 版本发布流程自动化

### 性能优化

- [ ] Redis 缓存层 (Session, Rate Limit, 邮件列表)
- [ ] 邮件列表虚拟滚动
- [ ] 图片懒加载 + CDN
- [ ] 数据库查询优化 (N+1 消除)
- [ ] 前端 Bundle 分析与优化

### 移动端优化

- [ ] 响应式布局完善
- [ ] 触摸手势 (滑动删除/归档)
- [ ] 推送通知 (PWA Push API)
- [ ] 离线邮件阅读 (Service Worker)

---
